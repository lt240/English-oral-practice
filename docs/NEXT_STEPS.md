## 一、本轮（第三轮）已完成的修复

### 1. 「软件打不开」—— 已修复
- **根因一（启动崩溃）**：`main()` 里 `sherpa.initBindingsAsync()` 在真机上原生库初始化失败会白屏/闪退。已加 try-catch 兜底，失败时 `asrReady=false`，App 仍能正常启动，仅跟读识别功能降级不可用。
- **根因二（安装冲突）**：包名已从 `com.example.ted_companion` 改为 `com.tedmate.companion`。若手机还装着旧包，会因签名/包名冲突「打不开」。**旧包必须卸载后重装**。

### 2. 中文翻译 —— 已全部完成
- 8 篇 ASR 识别稿共 **1318 句**中文翻译已逐条完成，并精确对齐到英文句数（`ted_meaning_of_life` 300 句、`ted_self_criticism` 204 句、`ted_not_personal` 182 句、`ted_mind_control` 151 句等）。
- 修复了 8 处「中英句数错位」：ASR 机械断句产生的碎片句（如 "Room."、"Days whatever."、"Try."、"Mean." 等）此前被合并翻译导致句数不匹配，现已逐处补句/合并，做到 8 篇全部 `中文句数 == 英文句数`。
- 译文已通过 `apply_zh.py` 回填内容 JSON 的 `translation` 字段，并重编译 `speech_library.g.dart`。

### 3. 单词发音 —— 已增强健壮性
排查结论：**有道音源本身正常**（实测 HTTP 200，返回标准 ID3 标签 MP3，约 8~25KB/词）。问题出在客户端健壮性，已增强：
- 下载内容校验：只接受 `audio/*` / `mpeg` 内容类型，并校验 MP3 魔数（`ID3` / MPEG 帧同步），**避免把有道偶发的 HTML 错误页当成 MP3 缓存**（这是「点了没声音」的最可能原因）。
- 缓存校验：缓存文件 < 1500 字节或损坏时自动重新下载。
- 播放等待超时从 8s 放宽到 12s，避免长词/弱网时误判。

> ⚠️ 注意：单词发音**首次播放必须联网**（下载一次后永久本地缓存）。离线状态第一次点喇叭会失败，这是设计使然。

## 四、最终目标

把「TED 跟读助手」做成一款**能真正留住人的英语跟读产品**，完整闭环是：

> **听原声 → 逐句跟读 → 看到逐词/音素级反馈 → 听到自己的录音对比 → 错词自动进生词本 → 按遗忘曲线每日复习 → 看到自己的进步曲线**

技术路线已经验证可行（VAD + 端侧 Whisper + 编辑距离对齐），内容也补到了 14 篇全有文稿、8 篇有中译。接下来最缺的不是「更多功能」，而是把**反馈闭环**（录音对比 + 可信评分 + 系统化复习）做扎实，让「练习」真正变成「进步」。
